# LOLGlobs — Glob-Based Command Obfuscation Catalog

Vendored data from [0xv1n/LOLGlobs](https://github.com/0xv1n/LOLGlobs)
(MIT licensed), pulled 2026-07-18. `entries.json` is a consolidated,
locally-queryable version of the project's `_globs/<platform>/<binary>.md`
catalog (66 entries: 32 Linux, 16 Windows CMD, 14 PowerShell, 4 macOS) —
the upstream repo's own `api/entries.json` is a Jekyll build-time template,
not static data, so it isn't fetchable directly; this file was generated by
parsing the YAML frontmatter out of each `_globs/**/*.md` entry instead.

## What it's for

Shells expand wildcard patterns (`*`, `?`, `[]`, brace/extglob expansion)
*before* a command executes, so a binary can be invoked without its literal
name ever appearing in the command string — e.g. `w?oami` resolves to
`whoami`. That defeats naive signature/string-based detection (AV, EDR,
WAF, command-line logging alerts) without changing what actually runs.
Upstream frames this explicitly as "educational and defensive security
purposes" — same spirit as this vault's use: authorized lab targets only,
per the root `CLAUDE.md` boundaries.

## When to use it

Only reach for this when a payload/command is actually observed being
blocked or altered in a way consistent with literal-string detection (a
WAF stripping a keyword, an EDR alert firing on a specific binary name,
etc.) — not preemptively on every box. Most HTB/lab targets have no
AV/EDR in the loop at all, so this is a targeted tool for the boxes where
it's actually relevant, not a default step.

## How to query it

Each entry has `Name`, `Platform` (`linux`/`macos`/`windows-cmd`/
`powershell`), `Category`, `MitreID`, `BinaryPath`, and a `Patterns` array
(`Pattern`, `Wildcards`, `Notes`). Example lookup:

```bash
python3 -c "
import json
entries = json.load(open('entries.json'))
hits = [e for e in entries if e['Name'] == 'whoami' and e['Platform'] == 'linux']
for e in hits:
    for p in e['Patterns']:
        print(p['Pattern'], '--', p['Notes'])
"
```
