# OverTheWire Queue

Generator id: `keep-working-overthewire`.

Same format as `htb.md`: one target per line, `[ ]` queued / `[x]` done /
`[!]` blocked. For OverTheWire, a "target" is a wargame+level (e.g.
`bandit24`) rather than a bare host — the recon-agent will need the
game's SSH host/port convention noted here since it isn't discoverable
via nmap the way an HTB box is.
